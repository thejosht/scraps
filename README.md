# Scraps

Scraps is a responsive-first food decision app that helps users quickly decide what to cook with ingredients they already have.

It is not a generic AI recipe generator. The product promise is: open Scraps, tap what you have, choose a vibe, and get realistic meal ideas fast.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Verify

```bash
npm run lint
npm run typecheck
npm run build
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the placeholder foundation page.
