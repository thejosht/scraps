# Scraps Design System

## Design Direction

Scraps should feel like premium playful utility: warm, modern, tactile, efficient, and satisfying to use. It should not feel childish, cartoony, goofy, or like a cheap AI wrapper.

## Experience Qualities

- Fast: users can make a decision in a few taps.
- Calm: suggestions feel grounded and not noisy.
- Warm: food choices should feel inviting.
- Adult-friendly: playful details should be restrained and polished.
- Responsive-first: mobile is excellent, desktop is purpose-built.

## Early Token Intent

- Color: warm neutrals, food-adjacent accent colors, and high-contrast text.
- Type: clean sans-serif with clear hierarchy and readable compact controls.
- Radius: soft but not pill-only; use shape intentionally.
- Motion: subtle feedback for selection and ranking changes later.
- Density: mobile controls should be thumb-friendly; desktop should use space for comparison and scanning.

## Component Direction

- Ingredient and vibe controls should be quick to scan.
- Recipe result cards should emphasize decision criteria: fit, effort, time, cleanup, and substitutions.
- Avoid decorative UI that competes with the user's decision.
